# BGTK FOOD — вкусная перемена

Веб-приложение для предварительного заказа еды в столовой Балхашского гуманитарно-технического колледжа имени А. Мусина.

**[Демонстрационное приложение](https://bgtk-food-campus.crispfawn2.chatgpt.site/)** · [Паспорт проекта и тестовые задания](docs/project-passport-and-test-cases.txt)

## Назначение
Сокращение очередей и упрощение взаимодействия посетителя и кухни: меню → корзина → заказ → приготовление → выдача.

## Возможности исходной сборки
- Русский и казахский интерфейсы, поиск, фильтры, избранное.
- Корзина, повторная серверная проверка цен и остатков, история заказов.
- Очередь кухни, интервалы выдачи, QR-коды, управление меню и остатками.
- Защита от повторной отправки заказа; обработка сетевых ошибок.
- PWA, адаптивный интерфейс, светлая и тёмная темы.

## Архитектура
В предоставленном архиве от 29 октября 2026 года: Next.js, React, TypeScript, Tailwind CSS, Zustand, Zod, Vinext, Cloudflare Workers / D1 / R2, Supabase PostgreSQL / Auth / Storage. Демонстрационные сессии изолированы по браузерам. Для совместной работы независимых устройств необходим настроенный production-режим Supabase. В этой сборке также предусмотрена роль кассы; это не подтверждение более поздней версии без кассира.

## Проверка и запуск
Для полной сборки необходимы исходники, Node.js 22.13+, pnpm 11.25.0 и, для production, собственный проект Supabase с применёнными миграциями. Проверка реальных заказов между устройствами требует отдельного запуска. Не вводите настоящие платёжные данные в демонстрацию.
